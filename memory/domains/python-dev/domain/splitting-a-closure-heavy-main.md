## splitting a long Python main() of nested closures into modules - state object first, then byte-identical moves a verifier proves; survivors checked on the base

A main() whose phases share state through nested closures cannot be split by
pure moves. Do it in two kinds of commit (j30, tools/fabric/assemble.py ->
tools/fabric/assembler/, 2026-10-05):

1. One in-place semantic commit. symtable lists each nested function's free
   variables (`get_frees()`) and any nonlocal rebinding. The locals that cross
   phases become fields of one dataclass (Run). Each stretch of main() becomes
   a phase function over it, and each closure a module function with `run`
   first. Generate the rewrite with tokenize (NAME -> run.NAME by position,
   skipping attributes and keyword-argument names; `run, ` added to calls of
   lifted functions). Print every lifted name used as a value (passed as a
   callable) for a hand fix with functools.partial.
   Check it with: py_compile; a symtable "global read but not bound" scan,
   with a positive control; the names local to two or more phases, reviewed
   for a read before the phase binds them; the unchanged oracle; mutations.
2. Moves, one module per commit, generated by a script that copies each
   top-level block (with the comment lines above it) byte for byte. Only
   file heads, imports and blank lines are written. A verifier asserts every
   source block appears in exactly one output, and a planted one-character
   change must make it fail. Collect imports with symtable globals, not
   ast.Name: a local loop variable named like an import (`field`) would add an
   import that ruff reports as F811.

**Why:** a surviving mutation is a gap in the oracle, not proof of the
change. Planting the same mutation on the base tells which: 4 of 12 survived
on both base and change. New cases went in a NEW test file (the old suite
stays unchanged as the oracle), committed BEFORE the refactor. Each one
passed on base and was caught under the base mutation.
**How to apply:** also run a real-input differential. Harvest a bundle of
my own memory (`harvest_memory.py --all --bundle`). Assemble it in two
detached worktrees (base, head), each with `--fabric`/`--working-copy`
pointing at itself. Compare stdout, stderr, exit and every changed file.
ruff is not installed on the host; `pip install --target <scratch> ruff`
gives CI's rule set (ruff.toml).
A commit can fail when the OpenTimestamps step of signing gets no
attestation within its timeout. The checks have already passed, so retry
the commit; do not redo the work. See [[facade-split-monkeypatch-trap]] and
[[oracle-blind-spots-in-ports]].
