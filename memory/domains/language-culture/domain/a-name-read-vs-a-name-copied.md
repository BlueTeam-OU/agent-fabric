## A personal name that is read aloud goes in Georgian script; one that is copied (a contact line beside an email and a domain) stays Latin — and an institution is called by the name it uses for itself, which is worth checking on its own site.

**A name you read is Georgian; a name you copy is Latin.** On a deck's team slide, "ანდრეა ბენეტონი" / "თორნიკე კაპანაძე" — Latin there puts the founders outside the team the slide says is being built here; in the contact line, beside an email and a domain, the same name stays Latin because it is transcribed into a phone and matched to a signature. Emails, domains and company names (BlueTeam, [redacted] on Wheels) are always Latin. **Call an institution by the name it uses for itself, and check that on its own site.** gita-pitch called the host "ქუთაისის ტექნოპარკი"; GITA's own site calls it "ქუთაისის ტექნოლოგიური ჰაბი" (techhub.gita.gov.ge) and its regions page "ტექნოპარკი ქუთაისი" — ours was the only form they do not use. The converse too: "საქართველოს ინოვაციების და ტექნოლოგიების სააგენტო" breaks the normative "ინოვაციებისა და", but gita.gov.ge writes it that way — the self-name wins and the correction would have been false. One move settles both: a Georgian-index web search plus the institution's own domain.
