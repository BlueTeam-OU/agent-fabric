## In a Georgian status cell a bare participle takes the row's subject, the person; name the verb's object (the identity link), and bare "ბმა" reads as a hyperlink or an employment link

The existing rule (a label speaks about the record, not the person) gains
one Georgian mechanism: in a status column a bare participle ("გაწყვეტილი",
severed) takes the row's subject, and the row is a person — and the
neighbouring badges ("აქტიური", active, which really is about the driver)
teach the reader that the column describes the man. A header cannot fix
it: it rescues one badge and spoils the others. The way out is to name
the verb's object: "ვინაობის ბმის გაწყვეტა" (severing the identity link),
not "მძღოლის გაწყვეტა" (a person as the object reads physically) and not
bare "ბმა" (first a hyperlink; beside a person, the working link with
them). The act and the badge may name different things (gzapp: the act is
done to the identity, the badge is the state of the driver record) — ask the
meaning's owner what the subject is first. Read a policy ban someone relays
in the ADR itself: "the anonymisation route is closed" was an inverted
reading, and a day went into working around a constraint that did not exist. Three independent cold reads stopping on the
same word is evidence, not taste.
