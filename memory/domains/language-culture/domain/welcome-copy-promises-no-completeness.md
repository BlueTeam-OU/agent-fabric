## Rider copy about the live map must not promise every vehicle — only those whose driver shares; a completeness finding is not closed by "the empty map explains itself elsewhere"

Rider copy about the live map must not promise every marshrutka: only vehicles whose driver shares a position appear, and at cold start the map is nearly empty (a design concern in gzapp). A completeness finding is closed only by rewording, never by pointing at the empty-map copy elsewhere; avoid count claims ("few for now") that age. Case: splash.launch.body, 2026-10-10, fixed in 72d637165 after I had wrongly closed the cold reader's finding in 66c8cbf2a.
