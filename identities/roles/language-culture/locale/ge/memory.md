პასუხობს.

**რა არის ფუნქცია.** შენი ქარტია და ბრიფი (ამ პრომპტში) ამბობს, რა არის
როლი და როგორ მუშაობს ის ყველგან. როლის მანდატი ამ პროექტში —
`<working copy>/.agent-fabric/roles/{role}.md`, რომელსაც სესიის
დაწყების ჰუკი გაწვდის — ამბობს, რას ფარავს ის *იმ რეპოზიტორიაში, სადაც
ხარ*, და რა უნდა წაიკითხო იქ პირველად.

**რა არის ჭეშმარიტი.** გამოხდილი ნაჭრები, თითოეული — მტკიცება,
რომელსაც წარმომავლობა ახლავს: `agent-fabric/memory/domains/{role}/` დარგისთვის და
`<working copy>/.agent-fabric/memory/{role}/` იმ სისტემისთვის, რომელზეც
მუშაობ. წინასწარ ნუ წაიკითხავ მათ. შენი როლის `INDEX.md` პროექტში
ყოველ ნაჭერს ერთსტრიქონიანი მინიშნებით ჩამოთვლის; როცა ის, რასაც
აკეთებ, მინიშნებას ემთხვევა, გახსენი ის ნაჭერი და არც ერთი სხვა.
`solution` ნაჭრები ძველდება: სადაც რომელიმე მათგანი ხეს არ ეთანხმება,
ხე ფაქტია.

**რა შეგემთხვა შენ.** შენი საკუთარი Claude-ის მეხსიერება, თითო ფაილში
თითო ფაქტი, სადაც ახალი მყარი ფაქტი პირველად იწერება. მეხსიერება საერთო
კორპუსამდე მხოლოდ დრენაჟით აღწევს (`memory/README.md`), და დრენაჟი
ფაილს მხოლოდ მაშინ იღებს, თუ მის `metadata:` ბლოკში `roles_class`
წერია:

```markdown
---
name: <short-slug>
description: <the one-line cue under which someone would want this>

  type: project
  roles_class: solution     # domain | solution | intersection | rationale | workflow | threads

```

`domain` დარგზეა, `solution` — ამ სისტემაზე, `workflow` — იმაზე, როგორ
მუშაობს როლი აქ, `rationale` — გადაწყვეტილების მიზეზებზე, რომლებიც
ჩანაწერს ელოდება, `threads` — ღია თემაზე, `intersection` — მტკიცებაზე,
რომელსაც ორი როლი იზიარებს. `roles_class`-ის გარეშე ფაილი მხოლოდ
შენია — დრენაჟი მას გამოტოვებს და ასახელებს. მხოლოდ შენი საკუთარი
home-საქაღალდე იკითხება; სხვა ანგარიშის მეხსიერებას დრენაჟი არ ეხება.
დრენაჟი გააკეთე მას შემდეგ, რაც როლის მუშაობის წესის ცვლილება
დაჯდება, და სულ მცირე კვირაში ერთხელ, სანამ აქტიური ხარ;
fabric-coordinator-ის მფლობელი აკეთებს კომიტს იმისა, რასაც გამოხდის,
შენი სახელით ნაჭრის `origin`-ში. **ადამიანებს როლით ასახელებ, არასოდეს
სახელით** — CEO, მფლობელი, აგენტი — ლოგინით: ნაჭერი ყოველ
რეპოზიტორიაში გადადის, და დრენაჟი ნაპოვნ სახელს ანაცვლებს
