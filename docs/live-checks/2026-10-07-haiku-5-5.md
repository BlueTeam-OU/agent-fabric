# 2026-10-07 — Claude Haiku 5.5 on the anthropic path, read back

The owner, 2026-10-07: "haiku 5.5 available, this must be anthropic default code-low". The model postdates this coordinator's training data, so its id was measured, as Sonnet 5.5's was (`2026-09-29-sonnet-5-5.md`).

The probes ran on develop-qzapp as user, on Claude Code 2.1.285, with plain `claude -p --output-format json`. The prompt, on stdin, was "Reply with the single word: ok".

## The id

| `--model` | `--effort` | init model | `is_error` | `modelUsage` | cost (USD) |
|---|---|---|---|---|---|
| `claude-haiku-5-5` | low | `claude-haiku-5-5` | false | `claude-haiku-5-5` | 0.085 |
| `claude-haiku-5.5` | low | `claude-haiku-5.5` | true | none | 0 |
| `claude-haiku-9-9-not-a-model` (control) | low | the same | true | none | 0 |

The two refused probes answered "There's an issue with the selected model". The control shows that the first row is the model answering, not a silent fallback.

## Through the alias, at the class's effort

`code-low` rides `haiku` (`runtime/claude-code/aliases.json`) and asks for `medium` (`routing/effort.json`). With `ANTHROPIC_DEFAULT_HAIKU_MODEL=claude-haiku-5-5`, `--model haiku --effort medium` was served:
- init model `claude-haiku-5-5`;
- `is_error` false;
- `modelUsage` only `claude-haiku-5-5`;
- 0.118 USD.

## Effort

- **Haiku 4.x takes no level.** `tools/fabric/routing.py` held every `claude-haiku-*` id to that, read from 2.1.280's bundled model registry (`2026-09-23-effort-registry.md`).
- **The registry does not list Haiku 5.5.** 2.1.285's registry has no entry for `claude-haiku-5-5`, so the harness takes it with its defaults for a Claude id.
- **The init events differ.**

  | model | `per_turn_effort_active` | `is_error` |
  |---|---|---|
  | `claude-haiku-5-5` | true | false |
  | `claude-haiku-4-5-20251001` (control, the same prompt at `--effort medium`) | false | false |

So the no-effort row is now `claude-haiku-4*`, and Haiku 5.5 falls under the catch-all `claude-*` (low to max). The routing check (`tools/fabric/routing.py check`) is clean with code-low at medium.

**Not measured:** whether medium is Haiku 5.5's own default; which level a session would use without the fabric's `--effort` (the launcher always passes it); and the quality difference from Sonnet 5.5 on the fabric's code-low work.

## What this decides

`routing/capabilities.json` `providers.anthropic.models.code-low` is `claude-haiku-5-5`, exported as `ANTHROPIC_DEFAULT_HAIKU_MODEL`. `code-medium` stays on `claude-sonnet-5-5`. ADR-005 §2 records the mapping. It reaches each account at its next launch after the distribution.
