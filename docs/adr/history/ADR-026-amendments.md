# ADR-026 — amendments

The full notes; the ADR's body reads current and its Amendments table lists them.

### Amendment 2026-10-09 — Comparing agents' resources is not ranking their work

ADR-046 adds a comparison view that sets agents' resources and job counts side by side. Rule 4 forbids comparing agents by `fabric-results`' verified-work number; this amendment says the rule covers that number only, so a view of operational facts is not a ranking of work. The owner approved the views on 2026-10-09.
