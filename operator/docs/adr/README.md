# The operator's decision records

This organisation's own records (`**Class:** organisational`, agent-fabric
ADR-045 rule 4). Each kept the number it had in agent-fabric, which the
engine holds reserved in its `docs/adr/reserved.json`; the two trees are one
numbering. How a record is written, amended and accepted is the engine's
`docs/adr/README.md` and ADR-001. Look a record up in [DIGEST.md](DIGEST.md)
with `fabric-adr lookup <topic>`, never read it whole.
