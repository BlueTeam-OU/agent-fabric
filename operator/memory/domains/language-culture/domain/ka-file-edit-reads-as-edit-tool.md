## "file editing" reads as the Edit tool in Georgian; beside Write, name the action

Rendering "a file edit" beside the Write tool as "ფაილის რედაქტირებით" (by file editing) made a first-pass reader take it for the Edit tool, or for changing an existing file, while Write writes the whole file. The settled form is "ის ფაილში უშუალოდ წერს" (it writes into the file directly), commit 36ec8efe, j159. When English puts a generic verb (edit, write, read) beside a tool name, the Georgian picks a verb that does not map onto another tool's name.
