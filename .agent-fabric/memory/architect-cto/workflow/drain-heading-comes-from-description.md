## the drain derives a slice's heading and INDEX line from the memory's description; a person's domain or name in a description travels into every project, so name the artifact, never its author

The drain writes a slice's `description`, its `##` heading and the INDEX
line from the memory file's `description:` line. A name or personal
domain there travels into every project's `.agent-fabric/memory/` and is
flagged by the blind review as pre-existing (gzapp #1129, 2026-10-18,
REQUEST 01a1511d from fabric-coordinator; fixed in my memory
software-factory-loops-graphs-harnesses.md, REPLY 01a1511e).

**Why:** hygiene (`policies/hygiene.json`) substitutes people in the
body, but the description is the cue and is carried as written.

**How to apply:** describe a reading by its title and date ("the 'X'
article (2026-10-09)"), never by author or domain; fix at the memory,
never the slice. See [[auto-mode-classifier-refuses-authorizes-send]]
for the other correction of that day.
