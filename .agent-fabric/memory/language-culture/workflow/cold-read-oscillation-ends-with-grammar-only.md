## when cold reads keep rewording the same sentence in turn, the last cold read checks grammar only

In j89 (2026-10-18, bb32f0eb, locale/ge/charter.md), three successive Georgian-only cold reads rewrote the same sentence three different ways. The third proposed the very wording that j89 had removed. Workers always find something to say about style, so the swing is not a new error. They cannot check against the source, so the bridge has to set the limit. Each fix is written from the source. If a third round swings the same spot in another direction, the final cold read asks about grammar only: case, agreement, verb form, commas. Style remarks are kept in the notes, not deleted. The two-pass rule still holds, because the final read is still cold and Georgian-only.
