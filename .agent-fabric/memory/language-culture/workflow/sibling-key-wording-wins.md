## A new dictionary key that twins an existing one keeps its wording; a first-pass rewrite of the new key alone is withdrawn

A new gzcoord key that is a variant of an existing one (carrier-title of delivery.title, cap.carrier-notice of cap.notice) keeps the existing key's Russian shape; a first-pass rewording of the new one alone is withdrawn on the second pass and recorded, and a bad shared wording is fixed in both keys in a separate commit.
